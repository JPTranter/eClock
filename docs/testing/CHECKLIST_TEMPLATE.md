# Testing Checklist Template

## Hardware Validation
- [ ] Board powers on correctly
- [ ] Battery charging circuit functional
- [ ] Display initializes without errors
- [ ] All buttons/controls responsive

## Display Testing
- [ ] Basic text rendering
- [ ] Different font sizes display correctly
- [ ] Partial refresh functionality
- [ ] Full refresh ghosting behavior
- [ ] Contrast and readability in various lighting

## Power Management
- [ ] Deep sleep mode functions
- [ ] Wake-up timer accuracy
- [ ] Battery level reporting
- [ ] Low battery warning activation

## Bluetooth Functionality
- [ ] BLE advertising broadcasts
- [ ] Time synchronization with Home Assistant
- [ ] Manual resync button operation
- [ ] Connection loss handling
- [ ] Data staleness indicators

## Long-term Reliability
- [ ] Extended operation without crashes
- [ ] Battery life meets specifications
- [ ] Display durability over time
- [ ] User satisfaction (wife approval)

## Documentation Verification
- [ ] Build instructions are clear and complete
- [ ] Code is well-commented
- [ ] Troubleshooting guide covers common issues
- [ ] External user can successfully build the project
